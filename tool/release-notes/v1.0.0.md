First public release of the Flutter version of Umbra Tags: a Windows image library that keeps your images in portable folders and runs its AI features fully offline.

### Highlights

- **Natural-language search.** Type "blue city at night" (Ctrl+K) and the gallery shows the closest images, ranked by SigLIP 2 text–image similarity. More results load as you scroll while they stay relevant.
- **Find similar.** Right-click any image to see the images that look most like it, in the main gallery with every image action available.
- **Find matching images.** For any tag, ranks the images that don't have it yet by similarity to the images already in the tag plus the tag's name, in a checkbox gallery with a large view. On the author's library this lifts held-out AUC from 0.645 (name only) to 0.835.
- **Reference tags.** Mark a tag as reference and its images only appear when you filter by that tag.
- **Resize.** A resize wizard with percentage breakpoints and a slider, plus a batch tool that steps through every image above a size threshold.
- **Tag tree.** Collapsible tags with tree guides, a resizable sidebar, and a status footer.
- **Crimson theme.** A custom title bar, Libre Baskerville throughout, a frosted-glass preview panel tinted by the image above it, and a dithered moon icon.
