1

Search moves to the centre

Natural-language search becomes the main control, with a Ctrl K shortcut and an example query as its placeholder. Import moves up from the status bar into the top bar's right end.

2

One saturated band

Full ultramarine is used only on the top bar, with a 4 px dither strip beneath it. Everything below uses deep blues, so images keep their real colour.

3

Counts in their own column

View and tag counts sit right-aligned in tabular figures. Long names ellipsize before the count, so “ARKVAIN (34…” becomes “ARKVAIN · 345”.

4

Row menus on hover

The ⋮ button appears only on the hovered or selected row. That removes a column of 14 dots from the tree. Right-click still opens the same menu.

5

Reference tags read at a glance

Italic, a paler blue, and a small REF badge, instead of an eye-off icon that looked like a hidden tag.

6

Selection bar

The active view gets a white edge bar and a lifted fill instead of red text, consistent with the white selection ring on tiles.

7

Selection ring and search scores

Selected tiles get an offset white ring and a check badge. In search mode each tile shows its similarity score.

8

Preview as a detail sheet

Filename, then a two-column metadata list (size, added, match score) instead of a large hash in display type. Tags gain an inline “Add tag”.

9

AI sort suggestions in place

The preview shows the top three suggested tags with dithered confidence bars. The number keys 1–3 accept, the same keys the AI sort review screen uses.

10

Indexing as a meter

The truncated “Similarity paused · 596 / 1370 i…” becomes a labelled dither meter with a Resume link. The last-received file is set in monospace.
